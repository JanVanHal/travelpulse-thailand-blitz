eSIM & mobile data for Thailand

Data on landing, or a Thai number from an airport booth. Check the phone first, then pick a plan. Prices live on the provider's site.

Last checked: 2026-10-21

What an eSIM is

An eSIM is a SIM built into the phone. You download a plan instead of inserting a plastic card. For a trip, that usually means buying data before you fly and turning it on when you land.

The full walk-through (compatibility, install, roaming off on the home line) is on TravelPulse: eSIM guide. This page is the Thailand choice, not a second copy of that guide.

Check the phone

The phone must support eSIM and it must be unlocked. Dial *#06#. An EID next to the IMEI means the hardware is there. iPhone: Settings, Cellular (or Mobile Service), Add eSIM. Android: the SIM manager varies by maker.

If there is no EID and no Add eSIM, buy a physical tourist SIM instead.

Install before you fly

  1. Buy and install on wifi at home. Installation uses the internet; it does not need to happen in Thailand.
  2. Read when the days start. Many plans start on first connection abroad. Leave the new line off until you land if that is the rule.
  3. On arrival, turn the eSIM on, set it as the mobile-data line, and leave data roaming off on the home line.

Data-only vs a Thai number

Most travel eSIMs are data only. WhatsApp, LINE and maps work. A Thai number is a different product, and it is what airport tourist SIMs give you. Some apps, banks and OTP flows ask for a Thai number. Confirm per app before you assume a data-only plan is enough for banking.
